# Flyer display font

Anton Regular is bundled, unmodified, from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/anton

Copyright 2020 The Anton Project Authors. See OFL.txt for the SIL Open Font License.
The `display` font option embeds this file and its license into each SVG master,
so the server and downloaded artwork do not depend on a remote font service or
the viewer having a commercial condensed font installed.

Existing `condensed` layouts retain their original system-font behavior.
