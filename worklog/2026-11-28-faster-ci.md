Backend CI took ~19 minutes because the database checks ran one after
another and each waited ~10 s for nothing after finishing. They now run in
two parts, one check per core, with the wait gone. The pytest parts stop
re-collecting the suite four times over.

How a new database check joins CI now: write `__tests__/<name>_db.mjs` (or
`scripts/<name>-db-check.mjs`). That's all; it runs. Don't add a line to
ci.yml. If a pytest test wants to pin that CI runs it, use
`from __tests__.db_checks_ci import runs_in_ci` and
`assert runs_in_ci("__tests__/<name>_db.mjs")`. A PR written before this
change that added a `node __tests__/x_db.mjs` line to ci.yml: on the
conflict, take main's ci.yml and drop the line.
